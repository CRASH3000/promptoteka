# Домашнее задание 4 и 5

## Домашнее задание 4

### Что было сделано

| Что сделано | Краткое описание |
|---|---|
| Формы авторизации | Добавлены формы входа, регистрации и восстановления пароля |
| Валидация форм | Для всех форм выводятся понятные ошибки под конкретными полями |
| Блокировка невалидной отправки | При ошибках форма не отправляется |
| Форма создания шаблона | В личном кабинете добавлена форма создания шаблона промпта |
| Редактор промптов | Вместо обычного `textarea` добавлен отдельный компонент `PromptEditor` |
| Подсветка синтаксиса | Добавлен предпросмотр промпта с подсветкой строк |
| GET-поиск шаблонов | Поиск работает через параметры в URL |
| Debounce | Подсказки появляются с задержкой, чтобы не делать лишние запросы |
| Минимум 3 символа | Поиск по тексту запускается только после ввода 3 символов |
| Восстановление из URL | После перезагрузки страницы поиск и результаты восстанавливаются |
| Loading / error / abort | Есть состояния загрузки, обработка ошибок и отмена запроса через `AbortController` |

### Основные страницы

| Страница | Что делает |
|---|---|
| `/auth/login` | Форма входа |
| `/auth/register` | Форма регистрации |
| `/auth/forgot-password` | Форма восстановления пароля |
| `/profile/templates/new` | Создание шаблона промпта |
| `/templates` | Поиск и фильтрация шаблонов |
| `/templates/:templateId` | Детальная страница шаблона |



## Домашнее задание 5

### Что было протестировано

| Тип тестов | Что проверяется |
|---|---|
| Unit-тесты | Валидация форм, поиск, фильтрация, подсветка синтаксиса |
| Integration-тест | Работа редактора промптов: кнопки изменяют содержимое `textarea` |
| E2E-тест | Пользовательский сценарий: регистрация, вход и создание шаблона |

### Файлы тестов

| Файл | Назначение |
|---|---|
| `src/utils/__tests__/authFormValidation.test.js` | Проверка валидации входа и регистрации |
| `src/utils/__tests__/templateFormValidation.test.js` | Проверка валидации формы шаблона |
| `src/utils/__tests__/templateSearchAndFilter.test.js` | Проверка поиска и фильтрации |
| `src/utils/__tests__/promptSyntaxHighlighter.test.js` | Проверка подсветки синтаксиса |
| `src/components/editor/__tests__/PromptEditor.test.jsx` | Интеграционный тест редактора |
| `e2e/userCreatesTemplate.spec.js` | E2E-тест создания шаблона |

### Используемые инструменты

| Инструмент | Для чего используется |
|---|---|
| `Vitest` | Unit и integration-тесты |
| `React Testing Library` | Проверка React-компонентов |
| `user-event` | Имитация действий пользователя |
| `Playwright` | E2E-тест в браузере |
| `jsdom` | Тестовая среда для компонентов |

### Команды запуска

| Команда | Что делает |
|---|---|
| `npm run test` | Запускает unit и integration-тесты |
| `npm run test:e2e` | Запускает E2E-тест |
| `npm run test:e2e:ui` | Запускает Playwright в UI-режиме |



## Проверка проекта

Установить зависимости:

```bash
npm install
```

Запустить проект:

```bash
npm run dev
```

Запустить unit и integration-тесты:

```bash
npm run test
```

Запустить E2E-тест:

```bash
npm run test:e2e
```

Запустить все тесты подряд:

```bash
npm run test && npm run test:e2e
```
